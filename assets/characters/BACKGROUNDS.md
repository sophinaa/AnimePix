# Transparent character sheets

Created using the built-in imagegen tool with `transparent_background: true`.
Original JPEGs are retained. The application uses the sibling `*-transparent.png` files.

## Prompts

### Jujutsu Kaisen

Use case: background-extraction. Edit target: supplied 720x948 sprite sheet. Remove only the white background to true alpha transparency, including gaps between limbs. Keep all six pixel characters, their exact colors (including white hair and highlights), black pixel outlines, poses, scale, positions, spacing, and small existing artist marks unchanged. Do not redraw, restyle, rearrange or add anything. Preserve the original canvas aspect ratio and full sheet composition so existing sprite crop coordinates remain usable. Output a transparent PNG asset for a website.
